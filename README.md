# Sandbox-cc

A test bed for developing a small web-based game remotely with Claude Code.

The working loop:

1. John sends instructions to a Claude Code session running on his home PC ("WORKY").
2. Claude edits files here, commits, and pushes to GitHub.
3. GitHub Pages serves the result so the app can be tried on an iPhone.

The game itself has not been chosen yet. The current `index.html` is only a
placeholder that proves the pipeline works end to end.

Live site: https://johnpendergrass.github.io/Sandbox-cc/

Project notes for continuity live in `claude-john-docs/`.
